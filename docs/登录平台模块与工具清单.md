## 2. 身份与鉴权接口（AI 必接）

| 接口 | 方法 | 路径 | 用途 | 对 AI 的意义 |
| --- | --- | --- | --- | --- |
| 登录 | POST | `/sys/login` | 密码+验证码登录 | 模式 A 自带登录页时可选 |
| **认票** | POST | **`/sys/loginByToken`** | 校验 token | **AI 认票主路径**（注意：不是 `/sys/login/loginByToken`） |
| **用户信息** | GET | **`/sys/user/getUserInfo`** | 当前用户 | 取人（username/userId） |
| **权限码** | GET | **`/sys/permission/getUserPermissionByToken`** | 菜单/权限/角色 | 取权，裁剪工具 |
| 权限码简化 | GET | `/sys/permission/getPermCode` | 权限码列表 | 工具 `permCode` 对齐 |
| 退出 | * | `/sys/logout` | 注销 | 过期引导 |
| SSO 授权码 | GET | `/sys/oauth2Server/getCode?clientId=` | 子系统 SSO | **模式 B** |
| SSO 换票 | GET | `/sys/oauth2Server/getTokenByCode` | code→token | 注册 `ai-bot` 后可用 |
| 子系统列表 | GET | `/sys/sysSubSystem/getSubSystemByUser` | 用户可见子系统 | 控制台入口/路由 |

**结论：** AI 侧 `amp.jeecg.*` 已按上述路径对齐；接入前在 `sys_sub_system` 登记 `ai-bot` + 角色绑定。

## 3. 系统能力面（50 Controller → 工具候选）

### 3.1 按域分类

| 域 | Controller | 只读接口（适合 AI 工具） | 写/危险（建议 HITL 或不上架） |
| --- | --- | --- | --- |
| **用户** | `SysUserController` | `list` / `queryById` / `queryUserRole` / `userDepartList` / `queryUserByDepId` | add/edit/delete/resetPassword/frozenBatch/import/export |
| **组织** | `SysDepartController` | `queryTreeList` / `queryMyDeptTreeList` / `searchBy` / `getUsersByDepartId` / `getDepartName` | add/edit/delete |
| **角色** | `SysRoleController` | `list` / `queryall` / `getRolesByToken` / `getListBySystemId` | add/edit/delete / saveRolePermission |
| **权限** | `SysPermissionController` | `getUserPermissionByToken` / `getPermCode` / `queryTreeList` / `queryRolePermission` | add/edit/delete / saveRolePermission / 数据规则写 |
| **字典** | `SysDictController` | `getDictItems/{code}` / `getDictText/{code}/{key}` / `loadDict` / `treeList` | add/edit/delete |
| **公告** | `SysAnnouncementController` | `listByUser` / `list` / `show/{id}` | add/edit/doReleaseData/delete |
| **消息** | `SysMessageController` | `list` / `queryById` | add（可考虑 ASK） |
| **日志** | `SysLogController` | `list` | deleteBatch（禁止） |
| **子系统** | `SysSubSystemController` | `list` / `getSubSystemByUser` / `getSubSystemByAppCode` | add/edit/delete |
| **登录/认证** | `LoginController` / `Oauth2Controller` / `ThirdLoginController` | `loginfo` / `getUserInfo` | login/logout/扫码/短信 |
| **文件** | `CommonController` / `SysUploadController` / `OssFileController` | — | upload/download（默认不进 Agent） |
| **其他** | Quartz / 数据源 / 在线用户 / 专家 / 人口 / CA / 重复检查… | 零星 list/query | 批量删、任务调度 |

### 3.2 建议首批 HTTP 工具（给 `biz-assist`，只读优先）

| 工具名 | 映射接口 | 权限码对齐 | 建议策略 |
| --- | --- | --- | --- |
| `query_my_info` | `GET /sys/user/getUserInfo` | 登录即可 | ALLOW |
| `query_user_by_name` | `GET /sys/user/list`（按 realname） | `system:user:query` | ALLOW（注意数据范围） |
| `query_dept_tree` | `GET /sys/sysDepart/queryMyDeptTreeList` | 登录/组织查询 | ALLOW |
| `query_dept_users` | `GET /sys/sysDepart/getUsersByDepartId` | 组织成员查询 | ALLOW |
| `query_roles` | `GET /sys/role/getRolesByToken` | 登录即可 | ALLOW |
| `query_dict` | `GET /sys/dict/getDictItems/{code}` | 字典查询 | ALLOW |
| `query_announcements` | `GET /sys/annountCement/listByUser` | 登录即可 | ALLOW |
| `query_my_menus` | `GET /sys/permission/getUserPermissionByToken` | 登录即可 | ALLOW |

> **不要**把 `delete*` / `resetPassword` / `importExcel` / `exportXls` / `saveRolePermission` 默认上架；若业务需要，单独工具 + **ASK** + 审计。

### 3.3 写操作示例（二期，HITL）

| 工具名 | 映射 | 风险 | 策略 |
| --- | --- | --- | --- |
| `send_message` | `POST /sys/message/sysMessage/add` | medium | ASK |
| `publish_announcement` | 公告 add/release | high | 默认 DENY / 人工 |
| `change_my_password` | `PUT /sys/user/changePassword` | high | 默认不上架（安全） |

## 4. 前端挂载点（ant-design-vue-jeecg）

| 项 | 位置/事实 | 接入动作 |
| --- | --- | --- |
| Token 存储 | `vue-ls` / `ACCESS_TOKEN`（`src/api/api.js` 等） | `AiBot` 读同一 token |
| 布局 | `src/components/layouts/`（TabLayout / RouteView） | 全局挂悬浮机器人 |
| 视图 | `src/views/{system,user,jeecg,bussiness,dashboard…}` | 业务页局部「问 AI」 |
| SSO | `src/cas/sso.js` | 门户带票跳转可复用 |
| 组件库 | `src/components/jeecg/` | 可放 `AiBot.vue` 同级 |

```vue
<!-- 建议挂在 BasicLayout / TabLayout -->
<AiBot
  :token="Vue.ls.get(ACCESS_TOKEN)"
  client-id="ai-bot"
  :agent-id="'biz-assist'"
/>
```

## 5. 登录平台侧接入 Checklist

| # | 动作 | 负责侧 | 必要性 |
| --- | --- | --- | --- |
| 1 | `sys_sub_system` 注册 `client_id=ai-bot` | pc_platform | **必须** |
| 2 | `sys_sub_system_role` 绑定可用角色 | pc_platform | **必须** |
| 3 | 确认认票/用户/权限三接口返回 JSON | 双方联调 | **必须** |
| 4 | 网关路由 → AI 中台服务 | pc_platform 网关 | 推荐 |
| 5 | `AiBot` 组件挂布局 | 前端 | 主路径 |
| 6 | 首批 4～8 个只读工具登记到 AI `business_tool` | AI 中台 | 主路径 |
| 7 | Swagger/权限码文档给 AI 生成 `permCode` | pc_platform | 推荐 |

## 6. 与 AI 智能体分工的对应关系

| AI Agent | 用到登录平台什么 | 不做什么 |
| --- | --- | --- |
| **`biz-assist`** | 用户/组织/角色/字典/公告/菜单（上表只读工具） | 不改密码、不删用户、不发公告 |
| **`knowledge-qa`** | 不直接调登录平台 API（纯 RAG） | — |
| **`ops-auditor`** | 可选：`/sys/log/list` 只读 | 不 delete 日志 |
| **`console-bot`** | 不进登录平台业务（管 AI 中台自身） | — |

---

## 7. 一句话总结

**登录平台是 Jeecg 微服务（system 域 50 个 Controller），身份三接口 `/sys/loginByToken` + `/sys/user/getUserInfo` + `/sys/permission/getUserPermissionByToken` 已可对齐 AI 侧 `amp.jeecg`；业务工具首批建议只读 8 个（用户/组织/角色/字典/公告/菜单），写类一律 HITL 或不上架；前端在 `ant-design-vue-jeecg` 布局挂 `AiBot` 读 `Vue.ls` 的 `ACCESS_TOKEN`。**
